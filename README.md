## About

This repository contains the source code for my engineering portfolio and technical case studies across ML systems, AI infrastructure, distributed systems, performance engineering, robotics data tooling, search evaluation, and reproducibility.

I focus on understanding how systems behave in practice — how they scale, where they regress, how memory and communication affect performance, and how evaluation can be made more reproducible.

---

## Selected Work

| Project | Focus |
|---|---|
| [**LeRobot State Atlas**](https://github.com/OmprakashSahani/lerobot-state-atlas) | LeRobot dataset analysis, forward kinematics, dual-arm trajectory playback, and 3D workspace coverage |
| [**Codex Benchmark Guardian**](https://github.com/OmprakashSahani/codex-benchmark-guardian) | Evidence-backed performance regression detection, protected verification, and bounded Codex repair workflows |
| [**SearchEval Lab**](https://github.com/OmprakashSahani/searcheval-lab) | Search and retrieval evaluation with TF-IDF, BM25, hybrid retrieval, ranking metrics, and regression analysis |
| [**Atlas AI**](https://github.com/OmprakashSahani/atlas-ai) | Distributed training, transformer inference, profiling, benchmarking, observability, and model serving |
| [**Distributed Training Profiler**](https://github.com/OmprakashSahani/dist-training-profiler) | Communication, memory, scaling, GPU-fit, and distributed-training performance analysis |
| [**ML Reproducibility Auditor**](https://github.com/OmprakashSahani/ml-repro-audit) | GitHub repository auditing for reproducibility, engineering quality, and ML systems signals |
